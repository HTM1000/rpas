================================================================================
QUANDO USAR ESTES ARQUIVOS:
================================================================================

1. DESENVOLVIMENTO:
   - Use mouse_position_helper.py para capturar novas coordenadas
   - Use capturar_tela_referencia.py para screenshots de referência
   - Consulte a documentação extra para entender implementações antigas

2. TESTES:
   - Use os arquivos *_TESTE.* para testar sem afetar produção
   - Execute scripts teste_*.py para validar funcionalidades específicas
   - Use debug_*.py para investigar problemas

3. DOCUMENTAÇÃO:
   - Consulte os README_*.md para contexto histórico
   - Use como referência para entender decisões de design
